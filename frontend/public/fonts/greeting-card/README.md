WOFF2 subsets from Google Fonts CSS API, downloaded 2026-10-16:
https://fonts.googleapis.com/css2?family=Noto+Serif:wght@400;700&display=swap

The Latin, Latin Extended and Vietnamese subsets share the same variable font
and support normal and bold card text. These files are served locally so card
previews and printouts do not depend on Google Fonts at runtime.
